# Barra de trabajo y apariencia

La versión 0.2.4 usa azul navy con acentos dorados. Los botones responden al
pasar el cursor, al pulsarlos y al recibir foco de teclado. Si Windows tiene
activada la reducción de animaciones, la interfaz respeta esa preferencia.

En la parte superior, pulse el nombre de la lotificadora con la que desea
trabajar. La seleccionada se muestra en navy con una línea dorada y una marca.
Solo se muestran las lotificadoras que el usuario tiene asignadas.

La opción Todas las lotificadoras aparece para el superusuario en los módulos
que admiten consulta global. Al entrar a un módulo que requiere una entidad,
se selecciona una lotificadora individual. Actualizar datos conserva la selección.

Si no caben todos los nombres, desplace la barra o use los botones de flecha.
También puede usar Tab para llegar a una lotificadora, flechas izquierda/derecha
para cambiar, Inicio para ir a la primera y Fin para ir a la última.

Termine o guarde la operación antes de cambiar de lotificadora: al cambiar,
se cierran los formularios y se reinician los filtros y borradores del módulo.
